ABC Kids Android Project

یہ Android Studio project ہے، APK فائل نہیں۔ یہاں موجود ماحول میں Android SDK/Gradle build tool موجود نہیں، اس لیے APK کو یہاں compile کرکے تصدیق نہیں کر سکا۔

APK بنانے کا طریقہ:
1. کمپیوٹر پر Android Studio انسٹال کریں۔
2. Android Studio میں "Open" منتخب کرکے یہ project folder کھولیں۔
3. Gradle sync مکمل ہونے دیں اور اگر SDK platform 35 مانگے تو SDK Manager سے انسٹال کریں۔
4. Build > Build Bundle(s) / APK(s) > Build APK(s) منتخب کریں۔
5. بننے والی APK عموماً app/build/outputs/apk/debug/app-debug.apk میں ہوگی۔

ایپ انٹرنیٹ کے بغیر بھی حروف دکھاتی ہے۔ آواز Android WebView/ڈیوائس کی text-to-speech سہولت پر منحصر ہے۔
